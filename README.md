# Normalized Fields

A standalone, ACF-compatible WordPress plugin that stores field data in typed, pivot and lookup tables instead of `wp_postmeta`.

> [!WARNING]
> **Work in progress.** NF is under active development and not ready for use. Don't install it on a production site. A release will be announced when it's ready.

Status: Phase 0 (foundations). No plugin code yet.
